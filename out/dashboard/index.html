The value model — fitted on this snapshot, tested blind

Every figure below is computed from the sealed snapshot itself at run time — no hand-kept list of names, no typed-in constants. A protocol enters the board when the snapshot records no token of its own for it (no market cap, no CoinGecko id, no symbol), except CEX records, which are exchanges rather than farmable protocols. Protocols whose token already trades are never ranked; they are the fitting set, and they appear in the “already trading” list at the bottom with the market's own figures.

ln(mcap) = a + b·ln(TVL) + c·ln(1+age) + d·tanh(change7d/75) + category offset Fitted by ridge regression (λ = 30 on every term but the intercept) on the snapshot's live-token protocols. The slope b < 1 is the comps curve: the market pays a falling multiple as TVL grows, so implied value grows sublinearly with TVL. Category offsets are mean residuals shrunk by n/(n+12), so a one-protocol category cannot swing the board. Missing age counts as 270 days; unreported growth counts as flat.

Verdicts — FARM, THIN, SKIP

Every row carries a verdict from stated bars on the snapshot's own figures — the same figures the model scores, no separate judgement. FARM: a pre-token core protocol the fitted curve values at $10M or more, not in freefall (7-day change at or above −10%, or unreported), running at least a full quarter with no token (age 90+ days, or unreported), with medium-or-better model confidence. SKIP: TVL in freefall (7-day change below −15%), one of the smallest launches on the board (implied value under $3M), or a product of a live token valued under $5M. Everything else is THIN — farmable, but the case is thinner. Products cap at THIN: for a bridge or a liquid-staking receipt, the token that might still come is the speculative part, so the board never calls one a straight farm.
