How the implied value is computed

Every figure below comes from the sealed snapshot itself — no hand-kept list of names. A protocol enters the board when the snapshot records no token of its own for it (no market cap, no CoinGecko id, no symbol), except CEX records, which are exchanges rather than farmable protocols. Protocols whose token already trades are never ranked; they appear in the “already trading” list at the bottom with the market's own figures, and they are the calibration set for the model.

implied = TVL × multiple × momentum × maturity × breadth multiple = (n · mediancat + 4 · medianall) / (n + 4), clamped to [0.02, 2.5] — the median market-cap-to-TVL ratio of the category's live-token protocols, shrunk toward the snapshot-wide median by sample size n momentum = 1 + 0.5 · tanh(change7d / 75) — damped, so a one-week spike cannot dominate; unreported growth counts as flat maturity = 0.60 + 0.40 · ln(1 + age) / ln(1 + 1460) — time running with no token, saturating; unknown age counts as 270 days breadth = 1 + 0.025 · min(chains − 1, 10) — a small premium per extra chain
